# Database Tables Setup for Profile, Skills, and File Uploads

## 1. Profile Image Table

Run this in Supabase SQL Editor:

```sql
-- Create profile_image table
CREATE TABLE public.profile_image (
  id bigint generated by default as identity primary key,
  image_url text not null,
  image_type text not null check (image_type in ('jpeg', 'png', 'link')),
  file_name text,
  is_primary boolean default true,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);

ALTER TABLE public.profile_image ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read"
  ON public.profile_image FOR SELECT USING (true);

CREATE POLICY "Allow authenticated users to manage"
  ON public.profile_image FOR ALL 
  USING (auth.role() = 'authenticated')
  WITH CHECK (auth.role() = 'authenticated');

CREATE INDEX profile_image_is_primary_idx ON public.profile_image(is_primary);
```

## 4. Create Storage Buckets (For File Uploads)

In Supabase Dashboard → Storage:

### Create two buckets:

1. **resumes** - For PDF and Word files
   - Make public (so files are accessible)
   - Allow: .pdf, .docx, .doc

2. **profile-images** - For profile photos
   - Make public (so images are accessible)
   - Allow: .jpg, .jpeg, .png

   - Click Create

   - Make public
