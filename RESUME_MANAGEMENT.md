# Resume Management System - Complete Setup

## What's New

✅ **Database-backed Resume Management**
- Store multiple resumes in Supabase
- Support PDF, Word, and Link types
- Set primary resume for "Download CV" button
- View resumes in new window

## Quick Setup

### Step 1: Create Resume Table in Supabase

Go to **Supabase SQL Editor** and run:

```sql
CREATE TABLE public.resume (
  id bigint generated by default as identity primary key,
  title text not null,
  type text not null check (type in ('pdf', 'word', 'link')),
  file_url text not null,
  file_name text,
  is_primary boolean default false,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);

ALTER TABLE public.resume ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read"
  ON public.resume FOR SELECT USING (true);

CREATE POLICY "Allow authenticated users to manage"
  ON public.resume FOR ALL 
  USING (auth.role() = 'authenticated')
  WITH CHECK (auth.role() = 'authenticated');

CREATE INDEX resume_is_primary_idx ON public.resume(is_primary);
CREATE INDEX resume_created_at_idx ON public.resume(created_at DESC);
```

### Step 2: Add Resume Files

Go to your Supabase dashboard and add resumes. Example URLs:

```
Google Drive: https://drive.google.com/file/d/FILE_ID/view
PDF URL: https://example.com/resume.pdf
Word URL: https://example.com/resume.docx
```

### Step 3: Use on Home Page

1. **Login** as admin at `/admin-login`
2. Go to home page (`/`)
3. Click **"Edit Resume"** button
4. Add your resume with:
   - **Title**: Name for the resume (e.g., "Main Resume")
   - **Type**: PDF, Word, or Link
   - **URL**: Direct link to file
   - **Primary**: Check to make it the default for "Download CV"

### For Admins

## How It Works

### Database Schema
```sql
id              -- Unique resume ID
title           -- Resume name (e.g., "Main Resume")
type            -- 'pdf', 'word', or 'link'
file_url        -- Direct URL to the file
file_name       -- Optional filename
is_primary      -- Only one primary resume (default for download)
created_at      -- Creation timestamp
updated_at      -- Last modification timestamp
```

### Resume Types

| Type | Example | How to Get |
|------|---------|-----------|
| **link** | Google Drive | Share link from Google Drive (set to public) |
| **pdf** | Resume.pdf | Upload to cloud storage and copy link |
| **word** | Resume.docx | Upload to cloud storage and copy link |

## Getting Resume Links

### Google Drive (Recommended)
1. Upload resume to Google Drive
2. Right-click → Share
3. Change to "Anyone with the link"
4. Copy link: `https://drive.google.com/file/d/FILE_ID/view`

### Other Cloud Storage
- **Dropbox**: Share folder → Copy link
- **OneDrive**: Share → Copy link
- **AWS S3**: Make public → Copy URL
- **Vercel/Netlify**: Upload file → Copy public URL

## Using the Hook

```typescript
import { useResume } from '@/hooks/useResume';

const { 
  resumes,           // Array of resumes
  loading,           // Loading state
  error,             // Error message
  fetchResumes,      // Fetch all resumes
  getPrimaryResume,  // Get primary resume
  createResume,      // Add new resume
  updateResume,      // Edit resume
  deleteResume,      // Delete resume
  openResume         // Open resume in new window
} = useResume();

// Fetch on mount
useEffect(() => {
  fetchResumes();
}, []);

// Open primary resume
const handleDownload = async () => {
  const primary = await getPrimaryResume();
  if (primary) openResume(primary);
};
```

## Troubleshooting

### "No resume available" error
→ Add a resume in the admin resume dialog

### Resume won't open
→ Check URL is correct and publicly accessible

### Can't see admin buttons
→ Make sure you're logged in (check navbar for "Admin Panel" button)

### Resume not showing in dialog
→ Refresh page or check Supabase dashboard for the resume record

## Security Notes

- Public read policy allows anyone to see/download resumes
- Admin-only modifications (you control who can edit)
- All changes logged in `created_at` and `updated_at`
- Consider setting resume files to private URLs if confidential
