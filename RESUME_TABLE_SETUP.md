# Resume Table Setup

Run this SQL in your Supabase SQL Editor to create the Resume table:

```sql
-- Create resume table
CREATE TABLE public.resume (
  id bigint generated by default as identity primary key,
  title text not null,
  type text not null check (type in ('pdf', 'word', 'link')),
  file_url text not null,
  file_name text,
  is_primary boolean default false,
  created_at timestamp with time zone default now(),
  updated_at timestamp with time zone default now()
);

-- Enable RLS
ALTER TABLE public.resume ENABLE ROW LEVEL SECURITY;

-- Allow anyone to read
CREATE POLICY "Allow public read"
  ON public.resume
  FOR SELECT
  USING (true);

-- Allow authenticated users to insert/update/delete (admin only in your case)
CREATE POLICY "Allow authenticated users to manage"
  ON public.resume
  FOR ALL
  USING (auth.role() = 'authenticated')
  WITH CHECK (auth.role() = 'authenticated');

-- Create index for faster queries
CREATE INDEX resume_is_primary_idx ON public.resume(is_primary);
CREATE INDEX resume_created_at_idx ON public.resume(created_at DESC);
```

## Inserting Sample Resume Data

```sql
-- Insert a resume link
INSERT INTO public.resume (title, type, file_url, is_primary)
VALUES ('Resume - Google Drive', 'link', 'https://drive.google.com/file/d/YOUR_FILE_ID/view', true);

-- Insert a PDF link
INSERT INTO public.resume (title, type, file_url, file_name, is_primary)
VALUES ('Resume PDF', 'pdf', 'https://example.com/resume.pdf', 'resume.pdf', false);

-- Insert a Word document link
INSERT INTO public.resume (title, type, file_url, file_name, is_primary)
VALUES ('Resume DOC', 'word', 'https://example.com/resume.docx', 'resume.docx', false);
```

## Supported Formats

| Type | Description | Example |
|------|-------------|---------|
| `link` | Direct URL link (Google Drive, etc.) | `https://drive.google.com/...` |
| `pdf` | PDF file URL | `https://example.com/resume.pdf` |
| `word` | Word document URL | `https://example.com/resume.docx` |

## Usage in Code

```typescript
import { useResume } from '@/hooks/useResume';

const { fetchResumes, resumes, openResume, createResume, updateResume, deleteResume } = useResume();

// Fetch all resumes
await fetchResumes();

// Open a resume in new window
openResume(resumes[0]);

// Create new resume
await createResume({
  title: 'My Resume',
  type: 'pdf',
  file_url: 'https://example.com/resume.pdf',
  is_primary: true
});

// Update resume
await updateResume(id, {
  title: 'Updated Resume',
  is_primary: true
});

// Delete resume
await deleteResume(id);
```

**Note:** Make sure to update your resume URLs to point to actual files or valid links!
